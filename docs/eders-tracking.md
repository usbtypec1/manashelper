# Отслеживание Eders

## Возможности

- `/eders`: задания и тесты, фильтры «Сегодня», «7 дней», «Доступные», «Не сдано», «Ожидают оценки», «Без точного срока».
- `/materials`: каталог доступных активностей, сгруппированный сортировкой по курсу и разделу.
- `/materials текст`: поиск по предмету, разделу, названию и текстовому описанию; фильтры работают внутри результатов поиска.
- «Настройки → Уведомления → Eders» (также `/eders_settings`): напоминания за 24 и 2 часа, открытия, переносы срока, новые/изменённые материалы и скрытие архивных сроков.
- `/week`: расписание, открытия, сроки и впервые обнаруженные материалы.

Опрос по умолчанию каждые 30 минут. Уведомления о материалах объединяются по курсу и разбиваются на сообщения
до 3500 символов HTML. Неудачная отправка остаётся в очереди; при успешной отправке вся пачка помечается отправленной.
Сбой между отправкой Telegram и commit БД может привести к повтору: строгой exactly-once доставки Telegram не предоставляет.

Снимки и очереди персональны. Первый снимок аккаунта, впервые появившегося курса и переход со старого формата
снимка не рассылают историю материалов. Будущие напоминания при этом создаются. Изменения названия и текстового
описания уведомляют; перестановка или перенос между разделами — нет. Замена файла без изменения карточки,
содержимое существующей папки и новые сообщения внутри форума пока не отслеживаются.

## Получение данных

Используется общий `new_http_client()` / `login()` из `modules/obis/infrastructure/client.py`, как в экспортном скрипте `eders.py`. Cookie jar сохраняется для перехода
`/site/eders`; `sesskey` извлекается из ссылок или Moodle-конфигурации. Единственный POST в Eders — чтение списка
курсов методом `core_course_get_enrolled_courses_by_timeline_classification`, `classification=all`, `limit=0`.
Пагинация продолжается до пустого результата. Затем читаются страницы курсов и подробности заданий/тестов.

GET страниц Eders запрашивает `lang=en`; парсер также понимает турецкие даты в сохранённых страницах.
Приоритет часового пояса: эффективный `M.cfg.usertimezone` страницы курса, затем профиль аккаунта.
Неизвестные и конфликтующие даты не используются для напоминаний. Дата в названии не заменяет срок из полей Moodle.
Формы сдачи, запуска попыток, изменения профиля и выполнения материалов не отправляются.

Новая миграция `c94d3a291f08` добавляет настройку материалов. Старые снимки читаются новым кодом и тихо
обновляются при первом успешном опросе. При возврате на старую версию приложения следует учитывать, что она
не знает новые типы активностей в снимках; одного downgrade схемы для такого отката недостаточно.

## Проверка

Для тестов с БД использовать локальный Postgres и переменные окружения из `AGENTS.md`.

```sh
.venv/bin/pytest -q tests/test_eders.py tests/test_eders_tracking.py tests/test_eders_handlers.py tests/test_eders_materials.py
EDERS_HTML_DIR=r .venv/bin/pytest -q -s tests/test_eders_corpus.py
```

На 827 локальных HTML проверены полнота поддерживаемых карточек, отсутствие дубликатов, разбор дат,
отсутствие ключей сессии в публичных ссылках и сериализация снимков. Найдены 258 сроков сдачи/закрытия.
Приватная папка `r` исключена из Git; в CI остаётся обезличенный пример реальной темы `actual-theme.html`.
Страниц отдельных заданий в этой выгрузке нет, поэтому статусы сдачи проверяются отдельными тестовыми примерами.

HTTP-проверка использует реальные запросы к локальной Postman Simulation с фиктивными данными.
Мок основан на экспортном скрипте `eders.py`, публичном контракте Moodle и обезличенных HTML. Поиск мока владельца пропущен:
Postman CLI не авторизован. Подключать аккаунт для локальной проверки не требуется.

```sh
postman simulation run postman/simulations/eders.sim.yaml --port 4947 --no-history --output ndjson
# В другом терминале:
EDERS_SIMULATION_PORT=4947 .venv/bin/pytest -q tests/test_eders_http_flow.py
```

Проверяются вход, cookies/redirects, sesskey, тело AJAX, пагинация, загрузка курса/деталей,
HTTP 500 с HTML, некорректный JSON и ограниченный повтор при истёкшей сессии.
Живой Eders и отправка в настоящий Telegram в этих проверках не используются.
