# Задача: нарисовать 5 медалей для новых ачивок

## Куда и как

- Папка: `frontend/src/assets/`.
- Формат: PNG, размер и стиль как у существующих `achievement-*.png` в этой же папке
  (например `achievement-foodie.png`, `achievement-eldin-balasy.png`).
- Код менять не нужно: `frontend/src/achievementArt.ts` сам находит файл по имени
  `achievement-<ключ ачивки, где "_" заменено на "-">.png`. Пока файла нет, вместо медали показывается замок.
- Стиль: круглая иллюстрированная медаль. Маскот (человек из `reference/mascot.JPG`)
  совмещён с мемом, как в остальных медалях. Отдельная заблокированная версия не нужна:
  для неё уже есть общий замок в атласе `achievement-medals.png`.
- Цвет — это тон фона карточки в детальном окне (задан в `achievementArt.ts`);
  медаль должна на нём хорошо смотреться.

## После добавления

1. `bun run --cwd frontend --bun build`. Открыть Mini App и проверить, что медаль видна
   в коллекции и в детальном окне на своём цвете.
2. В `docs/gamification.md` перенести эти пять медалей из «Planned images without a file yet»
   в список «Current images» с коротким описанием сюжета.
3. Закоммитить только PNG и правку документации.
